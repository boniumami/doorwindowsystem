# 铝合金门窗用料计算器

浏览器端算料工具：输入洞口尺寸、开启形式、60/65/70/80 型材系列和玻璃型号，计算型材、玻璃、胶条、发泡剂、五金等用料。支持多樘工程汇总、室内立面图、Excel 与 A3 PDF 导出。

## 启动

```bash
# 安装依赖
npm install

# 同时启动后端 API 与前端
npm run dev
```

前端端口 5173，后端 API 端口 3001，开发时 `/api` 由 Vite 转发。登录后使用，默认管理员 `admin` / `admin123`，登录后请改密。

用户、工程、樘窗和单价保存在 SQLite（`data/app.db`），各客户端登录后看到同一份数据，管理员修改后约 8 秒内同步。

## 主要能力

- 窗型：固定、单/双扇内开内倒、单/双扇内开（上开下固）、悬窗、上固下开/下双开、左固右开、左开右固及对应上开下固两格窗型
- 宽洞口可选手动三格分格；两格窗型改左格内空宽
- 公式：框外沿 = 洞口 − 2×安装间隙；扇外沿 = 框外沿 − 系列号（双扇再除以 2，无竖中挺）
- 导出：工程清单、单樘/分樘报价、本樘/全部 A3 横向立面 PDF
